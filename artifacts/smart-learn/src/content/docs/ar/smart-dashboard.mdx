# دليل استخدام وإدارة لوحة التحكم الذكية (Smart Dashboard)

دليل شامل ومفصل خطوة بخطوة لاستخدام وإدارة **لوحة التحكم الذكية لموودل** (`local_smartdashboard`).

صُممت خصيصًا **للطلاب**، **والمعلمين**، **والمديرين**، **وأولياء الأمور / الموجهين**، **ومسؤولي الموقع** — لتحويل نظام موودل من مجرد مستودع تقليدي للملفات إلى مركز قيادة وتحكم ذكي ولحظي.

---

## نظرة عامة والبنية الأساسية

تجمع **لوحة التحكم الذكية** (`local_smartdashboard`) البيانات الحيوية من المقررات، والتسليمات، والدرجات، ومقاييس مخاطر الطلاب، والسجلات المالية في واجهة تفاعلية موحدة ومتجاوبة تدعم الوضعين الداكن والفاتح تلقائيًا.

### البيئات والأنظمة المدعومة

| المكوّن | الإصدارات المدعومة |
|---|---|
| **إصدارات موودل (Moodle)** | 4.0, 4.1, 4.2, 4.3, 4.4, 4.5, 5.0+ |
| **متطلبات PHP** | 7.4, 8.0, 8.1, 8.2, 8.3+ |
| **قواعد البيانات المدعومة** | MariaDB, MySQL, PostgreSQL |
| **توافق المتصفحات** | جميع المتصفحات الحديثة الداعمة لـ CSS Grid و Flexbox و Backdrop Filters |
| **تعدد اللغات ودعم RTL** | دعم مدمج كامل للغات **الإنجليزية**، **والإسبانية**، **والعربية** (مع محاذاة وتنسيق كامل للاتجاه من اليمين إلى اليسار) |
| **التكاملات الاختيارية** | `local_aihub` / موودل Core AI (`\core_ai\manager`)، `mod_adaptiveplan`، `enrol_programs` |

## التثبيت والإعداد السريع

### الخيار 1 — تنزيل ملف ZIP
1. قم بتنزيل أحدث ملف ZIP للإضافة من لوحة العميل أو صفحة الإصدارات.
2. في موودل، انتقل إلى **إدارة الموقع ← الإضافات ← تثبيت الإضافات**.
3. ارفع ملف ZIP وانقر فوق **تثبيت الإضافة من ملف ZIP**.
4. اتبع تعليمات الترقية التي تظهر على الشاشة لإنشاء جداول قاعدة البيانات والصلاحيات.

### الخيار 2 — الاستنساخ عبر Git
إذا كان لديك وصول إلى الطرفية (SSH/Terminal) على خادم موودل:

```bash
cd /path/to/moodle/local
git clone https://github.com/Smartlearn-edu/moodle_local_smartdashboard.git smartdashboard
```

ثم قم بزيارة **إدارة الموقع ← الإشعارات** لإكمال التثبيت.

> **هام:** يجب أن يكون اسم المجلد داخل مسار `/local/` هو **`smartdashboard`**.

## الوصول إلى لوحة التحكم والتنقل

### رابط الوصول المباشر
يمكن للمستخدمين الوصول إلى لوحة التحكم مباشرة عبر الرابط:

```text
https://your-moodle-domain.com/local/smartdashboard/
```

### إعادة التوجيه التلقائي واستبدال لوحة التحكم
عند تفعيل هذا الخيار من قِبل المسؤول، يمكن للوحة التحكم الذكية أن تستبدل لوحة تحكم موودل الافتراضية `/my/` بسلاسة للمستخدمين والأدوار المحددة فور تسجيل الدخول.

### تبديل مظهر القالب
تتكيف لوحة التحكم الذكية تلقائيًا مع لوحة الألوان المحددة من قِبل المسؤول (**الوضع الداكن** أو **الوضع الفاتح**)، بما يتطابق بسلاسة مع الهوية البصرية لمؤسستك التعليمية.

## دليل استخدام الطالب

عندما يسجل الطالب دخوله، تقوم لوحة التحكم الذكية بتخصيص الواجهة ديناميكيًا لإبراز المهام الأساسية، والتقدم الأكاديمي، والمواعيد النهائية القادمة، والدرجات.

```text
+-----------------------------------------------------------------------+
|  👋 مرحبًا بعودتك، أحمد!                                              |
|  [ 📚 المكتبة ] [ 📝 الواجبات ] [ 🏆 الأوسمة ] [ 💬 الرسائل ]         |
+-----------------------------------------------------------------------+
|  📚 مقرراتي الدراسية (بطاقات التقدم)                                  |
|  +-----------------------+  +-----------------------+                 |
|  | الأحياء 101           |  | علوم الحاسب 200       |                 |
|  | [============ 75%  ]  |  | [====== 35%         ] |                 |
|  +-----------------------+  +-----------------------+                 |
+-----------------------------------------------------------------------+
|  ⏰ المواعيد النهائية القادمة       |  📈 ملخص الدرجات الأكاديمية     |
|  🔴 حرج: تقرير المعمل (اليوم)       |  الأحياء: 92% (A)               |
|  🟡 يستحق قريبًا: اختبار 3 (يومان)  |  علوم الحاسب: 84% (B)           |
+-----------------------------------------------------------------------+
|  📅 جدول أعمال اليوم والخطة التكيفية                                 |
|  [x] قراءة الفصل الرابع (20 دقيقة)  -  [ ] حل الاختبار التجريبي (15 د) |
+-----------------------------------------------------------------------+
```

### لافتة الترحيب المخصصة
- تعرض اسم الطالب الكامل، وصورته الشخصية، وتحية سياقية ذكية.
- توضح عدد المقررات المسجل بها وشارات الحالة السريعة.

### شبكة الاختصارات السريعة القابلة للتخصيص
- حتى 10 أزرار اختصارات قابلة للتخصيص يحددها مسؤول الموقع (مثل: دليل المقررات، المكتبة الرقمية، مجموعات الدراسة، التقويم، الدعم الفني).
- تنقل بنقرة واحدة إلى الموارد الأكثر استخدامًا مع أيقونات FontAwesome التعبيرية.

### بطاقات تقدم وإكمال المقررات
- **أشرطة الإكمال المرئية**: نسبة تقدم لحظية محسوبة تلقائيًا من محرك إكمال الأنشطة في موودل.
- **معلومات ملخص المقرر**: عدد الطلاب المسجلين، وفئة المقرر، وروابط سريعة مباشرة إلى صفحة المقرر.

### الجدول الزمني للمواعيد النهائية المرمز بالألوان
يصنف جميع الواجبات والاختبارات والتسليمات القادمة حسب درجة الاستعجال:
- 🔴 **حرج (خلال 24 ساعة)**: مميز بشارة حمراء ملفتة للانتباه الفوري.
- 🟡 **يستحق قريبًا (من 1 إلى 3 أيام)**: مميز بشارة كهرمانية للمحطات القادمة.
- 🔵 **قادم (&gt; 3 أيام)**: مميز بشارة زرقاء/محايدة للتخطيط المستقبلي.
- **رابط التسليم المباشر**: انقر فوق أي بطاقة موعد نهائي للانتقال مباشرة إلى صفحة تسليم المهمة.

### ملخص الدرجات والتعمق الأكاديمي
- **لمحة فورية عن الأداء**: تعرض الدرجة الحرفية، والنسبة المئوية الحالية، والنقاط القصوى المتاحة عبر كافة المقررات النشطة.
- **تفصيل معمق وتفاعلي**: انقر على أي مقرر لفتح نافذة التحليل التفاعلية التي تعرض:
  - درجات الواجبات والاختبارات والمناقشات الفردية.
  - الأوزان النسبية، ونطاقات الدرجات، وتعليقات وملاحظات المعلم.
  - مجاميع الفئات والمجموع الكلي للمقرر.
- **تصدير كتقرير HTML / CSV**: تصدير تقرير الدرجات الشامل بنقرة واحدة للمراجعة دون اتصال أو لحفظ السجلات.

### جدول أعمال اليوم والخطة الدراسية التكيفية
- يتزامن تلقائيًا مع خطط الدراسة التكيفية في موودل (`mod_adaptiveplan`).
- يقسم جدول الدراسة اليومي إلى مهام مركزة ومحددة مع الوقت التقديري لإنجاز كل مهمة.
- قائمة مهام تفاعلية لتتبع ومتابعة الإنجاز على مدار اليوم.

### التحليل الذكي للأداء ومراجعة نقاط القوة
- **رؤى أكاديمية فورية**: مدعومة بالتكامل مع الذكاء الاصطناعي لتقديم تقييمات بناءة لنقاط القوة والمجالات التي تحتاج إلى تحسين.
- **نصائح دراسية موجهة**: توصيات دراسية مخصصة تستند إلى درجات التسليمات الأخيرة ومستوى التفاعل مع الأنشطة.

## دليل بوابة المعلمين والتربويين

صُممت بوابة المعلم للتخلص من التنقل الإداري المتكرر وتجميع كافة الإجراءات والمهام المطلوبة في شاشة واحدة منظمة.

### طابور التصحيح المركزي
- **طابور التسليمات عبر كافة المقررات**: يجمع جميع الواجبات غير المصححة والتسليمات المقالية المعلقة من كل مقرر تدرسه في مكان واحد.
- **أعداد التسليمات ودرجة الاستعجال**: يوضح عدد التقديمات التي تنتظر التصحيح، وأسماء الطلاب، وتوقيت التسليم.
- **التصحيح السريع بنقرة واحدة**: انقر مباشرة على أي صف تسليم لفتح واجهة تصحيح موودل في نافذة مخصصة دون الحاجة للتنقل عبر شجرة المقررات.

### تتبع تقدم وإكمال الطلاب
- مراقبة أعداد المسجلين ونسب الإكمال عبر جميع فصولك الدراسية.
- تصفية الطلاب حسب المقرر، أو المجموعة، أو الحالة.
- تحديد الطلاب المتأخرين عن وتيرة الفصل الدراسي قبل مواعيد الامتحانات بوقت كافٍ.

### نظام الإنذار المبكر المعياري للطلاب المعرضين للخطر
- **درجة المخاطر (0–100%)**: تُحسب يوميًا وتلقائيًا استنادًا إلى مؤشرات مرجحة:
  - **حداثة تسجيل الدخول / عدم النشاط**: ينبه عن الطلاب الذين لم يسجلوا دخولهم لعدة أيام.
  - **سرعة إكمال المقرر**: يرصد توقف أو تعثر إكمال الأنشطة.
  - **متوسط الدرجات**: يحدد الطلاب ذوي الدرجات المنخفضة أو المتراجعة.
  - **الواجبات المتأخرة**: يحصي المواعيد النهائية الفائتة.
  - **الالتزام بالخطة التكيفية**: يتتبع مدى إنجاز مهام خطة الدراسة المحددة.
- **شارات مستويات المخاطر**:
  - 🟢 **على المسار الصحيح (0–39%)**
  - 🟡 **تحت المراقبة (40–69%)**
  - 🔴 **معرض للخطر (70–100%)**
- **تفاصيل وإجراءات التدخل**: انقر على أي طالب معرض للخطر لعرض سجله الزمني المفصل وإطلاق إشعارات الدعم والتواصل.

### التعمق في إكمال الأنشطة
- فحص معايير الإكمال نشاطًا بنشاط لكل طالب على حدة.
- الاطلاع على تواريخ الإكمال الدقيقة، وسجلات المشاهدة، ومتطلبات التسليم.

## دليل بوابة أولياء الأمور والموجهين الشاملة (360°)

توفر بوابة أولياء الأمور والموجهين الشاملة للأوصياء والمرشدين الأكاديميين والرعاة رؤية واضحة وشاملة لمسيرة الطلاب الأكاديمية.

### مبدل المتدربين والإشراف على عدة طلاب
- التبديل بسهولة بين الأبناء أو الطلاب المخصصين لك عبر قائمة منسدلة بسيطة وسريعة.
- إمكانية تخصيص مسمى الدور (مثل: *ولي أمر*، *موجه*، *وصي*، *مرشد أكاديمي*، *راعي*).

### تصفية على مستوى البرامج الأكاديمية
- للمؤسسات التي تستخدم إضافة `enrol_programs`، يمكن للموجهين تصفية الطلاب حسب المسارات الأكاديمية، أو الدرجات العلمية، أو برامج الدفعات.

### مخططات تحليل تقدم الدرجات
- رسم بياني مرئي متعدد المحاور يوضح اتجاهات الأداء الأكاديمي على مدار الأسابيع أو الفصول الدراسية.
- مقارنة درجات المهام الفردية بمتوسط المقرر والدرجة القصوى الممكنة.

### رسوم الرادار لإتقان المواد والمهارات
- رسم رادار كفاءات متعدد الأبعاد يبرز نقاط القوة عبر المواد المختلفة ومجالات المهارات (مثل: الرياضيات، العلوم، الإنسانيات، البرمجة).

### الخرائط الحرارية للتفاعل الأسبوعي وعداد استمرارية الدراسة
- **كثافة النشاط اليومي**: توضح كثافة تسجيل دخول الطالب وتكرار تفاعله خلال كل يوم من أيام الأسبوع.
- **عداد استمرارية الدراسة (Study Streak)**: يعرض عدد الأيام المتتالية التي درس فيها الطالب لتشجيع الاستمرارية وبناء عادات إيجابية.

### مؤشرات الأداء الرئيسية (KPIs) وتنبيهات المخاطر
- شارات لحظية تسلط الضوء على الأمور الحرجة التي تتطلب مساندة ولي الأمر أو الموجه (مثل: الواجبات المتأخرة، انخفاض الحضور، تراجع نتائج الاختبارات).

## دليل المسؤولين والمديرين

يزود مركز الإدارة متخذي القرار بالمعلومات الشاملة على مستوى المؤسسة، ومراقبة الإيرادات المالية، والتقارير الذكية التلقائية.

### تحليلات التسجيل والفئات على مستوى النظام
- **إجمالي التسجيلات والمجاميع المباشرة**: تتبع التسجيلات النشطة الإجمالية مع تفصيل أعداد الطلاب الفريدين والتسجيلات المكررة.
- **توزيع أداء الفئات**: مقارنة كثافة وتفاعل الطلاب عبر الكليات والأقسام الأكاديمية المختلفة.
- **نسبة الطلاب إلى المعلمين**: مؤشر مرئي لحجم أعباء التدريس وتوزيع الدفعات.
- **تصدير بيانات CSV**: تصدير لقطات شاملة لتسجيلات المؤسسة لأغراض التقارير والتدقيق والمطابقة.

### تحليلات الإيرادات والمدفوعات
- **الإيرادات الفعلية مقابل التقديرية**: مخططات بيانية وخطية تفاعلية تقارن الإيرادات المتوقعة بالمبالغ المحصلة فعليًا.
- **تصفية عائد الاستثمار (ROI) للفئات**: تحليل الفئات الدراسية التي تحقق أعلى عائد مالي للمؤسسة.
- **نطاقات زمنية مخصصة وعملات متعددة**: تصفية السجلات حسب: كل الأوقات، اليوم، آخر 7 أيام، آخر 30 يومًا، العام الماضي، أو نطاقات مخصصة مع دعم تعدد العملات.
- **مجموعات بيانات محاسبية قابلة للتصدير**: تنزيل ملفات CSV بضغطة زر لعمليات الفوترة والتدقيق المحاسبي.

### التقارير السحرية بالذكاء الاصطناعي ومركز استعلامات SQL
تحويل الأسئلة باللغة الطبيعية إلى استعلامات SQL آمنة ومحسنة ومخططات بيانية تفاعلية.

1. **طرح السؤال**:
   - اكتب طلبك بلغة طبيعية وواضحة، على سبيل المثال:
     > *"اعرض لي أفضل 10 مقررات نشطة من حيث إكمال الطلاب خلال آخر 30 يومًا"*
     >
     > *"ما هي المقررات التي تحتوي على أكبر عدد من الواجبات المتأخرة؟"*
     >
     > *"أظهر توزيع الإيرادات الشهرية حسب فئات المقررات لعام 2026"*
2. **توليد الاستعلام بالذكاء الاصطناعي**:
   - استخدام إضافة `local_aihub` (مع دعم البديل الأساسي لموودل `\core_ai\manager`) لترجمة السؤال إلى استعلام قاعدة بيانات دقيق وقابل للتنفيذ.
3. **العارضات التفاعلية**:
   - تحويل نتائج الاستعلام تلقائيًا إلى رسوم بيانية تفاعلية (أعمدة، خطوط، دائري، رادار) أو جداول بيانات منسقة.
4. **إدارة التقارير**:
   - **حفظ التقرير**: حفظ التقارير المخصصة مع العناوين والأوصاف التوضيحية.
   - **مكتبة التقارير المحفوظة**: إعادة تشغيل التقارير، أو فحصها، أو حذفها في أي وقت.
   - **فحص استعلام SQL**: عرض وفحص كود SQL المُولد لضمان أعلى معايير حوكمة وأمان البيانات.

### تهيئة محرك قواعد المخاطر المعياري
يمكن تخصيص معايير وأوزان احتساب المخاطر عبر **إدارة الموقع ← الإضافات ← الإضافات المحلية ← لوحة التحكم الذكية (Smart Dashboard)**:

| إضافة القاعدة الفرعية | الغرض | المعلمات القابلة للتهيئة |
|---|---|---|
| `loginrecency` | مراقبة عدم نشاط الطلاب | الحد الأقصى لأيام الانقطاع (الافتراضي: 14 يومًا)، وزن القاعدة |
| `coursecompletion` | تتبع التقدم المتعثر في المقرر | عتبة نسبة الإكمال المستهدفة، وزن القاعدة |
| `grades` | التنبيه عند تدني متوسط الدرجات | درجة الرسوب/الحد الأدنى، وزن القاعدة |
| `safetynet70` | شبكة الأمان الأساسية (70%) | الحد الأدنى المستهدف (70%)، وزن القاعدة |
| `overdue` | رصد المواعيد النهائية الفائتة | الحد الأقصى للمهام المتأخرة المسموح بها، وزن القاعدة |
| `adaptiveplan` | تتبع الالتزام بالخطط التكيفية | عتبة إنجاز المهام اليومية، وزن القاعدة |

### إعداد وتكامل خطافات الويب (n8n Webhook)
أتمتة التنبيهات الخارجية الفورية (عبر SMS، Slack، Microsoft Teams، WhatsApp، البريد الإلكتروني) عند تجاوز الطلاب لحدود المخاطر.

1. في خادم **n8n** الخاص بك، أنشئ عقدة مشغل **Webhook** بطريقة `POST`.
2. في موودل، انتقل إلى **إدارة الموقع ← الإضافات ← الإضافات المحلية ← Smart Dashboard**.
3. ضمن قسم **تنبيهات الطلاب المعرضين للخطر**، أدخل:
   - **رابط n8n Webhook URL**: `https://your-n8n-instance.com/webhook/smartdashboard-alerts`
   - **رمز الأمان n8n Webhook Token**: رمز مصادقة Bearer الآمن الخاص بك.
4. عند احتساب درجات المخاطر للطلاب، يرسل موودل حمولة بيانات JSON إلى مسار عملك:

```json
{
  "event": "student_at_risk",
  "timestamp": 1787665313,
  "student": {
    "id": 42,
    "name": "سارة علي",
    "email": "sara.ali@example.com"
  },
  "course": {
    "id": 15,
    "fullname": "هياكل البيانات المتقدمة"
  },
  "risk": {
    "score": 85,
    "level": "high",
    "reasons": ["عدم تسجيل الدخول لمدة 12 يومًا", "تأخر تسليم الواجب الثاني"]
  }
}
```

### استبدال لوحة التحكم وإعادة التوجيه التلقائي
تحديد ما إذا كانت لوحة التحكم الذكية ستحل محل صفحة `/my/` الافتراضية في موودل:
- **تفعيل استبدال لوحة التحكم**: تشغيل/إيقاف.
- **الأدوار المطلوب إعادة توجيهها**: اختيار أدوار محددة (مثل: طالب، معلم، مستخدم مصادق عليه).
- **إعادة توجيه مسؤولي الموقع**: تحديد ما إذا كان يجب توجيه مديري النظام أيضًا.

### تخصيص مسميات أدوار أولياء الأمور/الموجهين
اختر التسمية المناسبة للعلاقة في كافة واجهات النظام:
- ولي أمر (Parent)
- موجه (Mentor)
- شريك (Partner)
- مشرف أكاديمي (Academic Supervisor)
- وصي (Guardian)
- راعي (Sponsor)

### تخصيص اختصارات الوصول السريع للطلاب
تهيئة ما يصل إلى 10 أيقونات في إدارة الموقع:
- **اسم الأيقونة**: التسمية التوضيحية التي تظهر أسفل الأيقونة (مثل: "المكتبة"، "الجدول"، "الدعم والمساعدة").
- **فئة الأيقونة (FontAwesome)**: فئة CSS للأيقونة (مثل: `fa-book`, `fa-calendar-check`, `fa-graduation-cap`, `fa-life-ring`).
- **رابط الوجهة**: الرابط الكامل الداخلي أو الخارجي المستهدف.

### إضافة كتل موودل القياسية إلى لوحة التحكم
لجعل أي كتلة في موودل قابلة للإضافة إلى صفحات لوحة التحكم الذكية، أضف `'local-smartdashboard-*' => true` إلى دالة `applicable_formats()` في ملف الكتلة:

```php
// Inside blocks/<blockname>/block_<blockname>.php
public function applicable_formats() {
    return [
        'course-view'            => true,
        'site'                   => true,
        'my'                     => true,
        'local-smartdashboard-*' => true, // <-- تفعيل للوحة التحكم الذكية
    ];
}
```

> **ملاحظة:** بعد تعديل أي ملف كتلة، توجه إلى **إدارة الموقع ← التطوير ← مسح ذاكرات التخزين المؤقت** لتحديث سجل الكتل في موودل.

## تحول سير العمل: موودل الافتراضي مقابل لوحة التحكم الذكية

| المهمة | سير العمل الافتراضي في موودل | سير العمل في لوحة التحكم الذكية | الوقت الموفر |
|---|---|---|---|
| **فحص التصحيح المعلق** | الدخول للمقرر ← فتح الواجب ← فحص التسليمات ← تكرار 10+ مرات | فتح لوحة التحكم الذكية ← عرض **طابور التصحيح** عبر جميع المقررات | **أسرع بنسبة 85%** |
| **تحديد الطلاب المعرضين للخطر** | تصدير السجلات إلى Excel ← حساب حداثة الدخول ومتوسط الدرجات يدويًا | فتح **تنبيهات المخاطر** ← شارات مخاطر فورية ومشغلات n8n Webhook | **أسرع بنسبة 95%** |
| **رؤى البيانات المخصصة** | كتابة استعلامات SQL معقدة في أدوات إدارة قواعد البيانات | استخدام **التقارير السحرية بالذكاء الاصطناعي** ← كتابة السؤال باللغة الطبيعية وعرض الرسم البياني | **أسرع بنسبة 90%** |
| **الخطة اليومية للطالب** | مراجعة تقويم كل مقرر على حدة | فتح **جدول أعمال اليوم** ← خطة دراسية يومية موحدة وتفاعلية | **أسرع بنسبة 80%** |

## استكشاف الأخطاء والأسئلة الشائعة (FAQ)

### س: لماذا تظهر صفحة بيضاء أو أنماط تصميم غير محدثة بعد الترقية؟
**ج:** يقوم نظام موودل بتخزين وحدات JavaScript AMD وملفات CSS بشكل مكثف في الذاكرة المؤقتة. انتقل إلى **إدارة الموقع ← التطوير ← مسح ذاكرات التخزين المؤقت** وانقر فوق **مسح جميع ذاكرات التخزين المؤقت**، ثم أعد تحميل الصفحة في متصفحك بقوة (`Ctrl + F5` أو `Cmd + Shift + R`).

### س: كيف أجعل لوحة التحكم الذكية هي صفحة الهبوط الافتراضية للطلاب؟
**ج:** انتقل إلى **إدارة الموقع ← الإضافات ← الإضافات المحلية ← Smart Dashboard**، وقم بتفعيل **استبدال لوحة التحكم (Enable Dashboard Replacement)**، ثم حدد **طالب (Student)** / **مستخدم تم التحقق منه (Authenticated user)** في قائمة **الأدوار المطلوب إعادة توجيهها**.

### س: لماذا لا تولد ميزة التقارير السحرية استعلامات SQL؟
**ج:** تأكد من تهيئة أحد الخيارين التاليين:
1. إضافة **AI Hub** (`local_aihub`)، أو
2. نظام الذكاء الاصطناعي الأساسي في موودل (`\core_ai\manager`) مع مزود ذكاء اصطناعي نشط تم ضبطه عبر **إدارة الموقع ← عام ← إعدادات الذكاء الاصطناعي**.

### س: أين يمكنني معرفة وقت تشغيل مهمة احتساب درجات المخاطر؟
**ج:** يعمل محرك احتساب المخاطر تلقائيًا عبر المهام المجدولة في موودل. يمكنك عرض المهمة أو تشغيلها يدويًا عبر **إدارة الموقع ← الخادم ← المهام المجدولة ← Calculate at-risk student scores** (`\local_smartdashboard\task\calculate_risk`).

### س: هل يمكن لأولياء الأمور الاطلاع على درجات طلاب آخرين؟
**ج:** بالتأكيد لا. يتم تطبيق نظام الصلاحيات وسياقات الوصول في موودل بصرامة بالغة. لا يمكن لأولياء الأمور والموجهين سوى الاطلاع على بيانات الطلاب المرتبطين بهم رسميًا من خلال تعيينات أدوار المرشد/ولي الأمر في موودل.
