لوحة تحكم تحليلية قوية وشاملة لنظام موودل (Moodle).
مصممة **للطلاب**، **والمعلمين**، **والمديرين**، **وأولياء الأمور / الموجهين**، **والمسؤولين** — مع واجهة جميلة تدعم الوضع الداكن.

## لمحة عن الميزات

### نظرة عامة على المقررات
- بطاقات المقررات مع أعداد الطلاب وصور مخصصة
- متصفح الفئات للمسؤولين مع إحصائيات التسجيل
- لافتة ترحيب شخصية للطلاب مع الصورة الرمزية وشبكة أيقونات اختصارات (حتى 10 روابط قابلة للتخصيص)

### تقدم الطلاب والمواعيد النهائية
- تتبع التقدم والإكمال عبر جميع المقررات المسجل بها
- تفاصيل إكمال الأنشطة لكل طالب بشكل معمق
- قائمة سجلات درجات الطلاب قابلة للتصفية ولمحة سريعة عن **ملخص الدرجات** (My Grades Summary)
- **الجدول الزمني للمواعيد النهائية المرمز بالألوان**: تصنيف الواجبات والاختبارات القادمة حسب الاستعجال (**حرجة** Critical، **تستحق قريبًا** Due Soon، **قادمة** Upcoming)
- تصدير مجموعات البيانات إلى ملفات CSV

### التصحيح وجدول الأعمال
- طوابير التصحيح المعلقة الموحدة عبر جميع المقررات التي تدرسها
- تفصيل الواجبات/المهام مع تواريخ الاستحقاق
- **جدول أعمال اليوم (الخطة اليومية)**: مزامنة جدول مهام الطالب ديناميكيًا (يتكامل مع خطط الدراسة التكيفية في موودل `mod_adaptiveplan`)

### بوابة أولياء الأمور والموجهين الشاملة (Parent & Mentor 360° Portal)
- **مبدّل المتدربين (Mentee Switcher)**: التبديل بسهولة بين الطلاب أو المتدربين المخصصين لك
- **تصفية البرامج**: تصفية المتدربين ديناميكيًا بناءً على البرامج المسجلين بها (عبر تكامل `enrol/programs`)
- **التحليلات المرئية**: عرض مخططات تقدم الدرجات، ورسوم الرادار لمدى إتقان المواد، والخرائط الحرارية للتفاعل الأسبوعي (Weekly Engagement Heatmaps)
- **مؤشرات الأداء الرئيسية (KPIs) للطلاب المعرضين للخطر**: عدادات استمرارية الدراسة (Study Streaks)، وإجمالي التفاعلات، وشارات التنبيه المبكر الفورية

### تحليلات النظام
- إحصائيات التسجيل على مستوى النظام بأكمله
- رسوم بيانية تحليلية وتتبع الأداء على مستوى الفئات
- تصور لنسبة الطلاب إلى المعلمين
- تصدير السجلات إلى ملفات CSV

### تنبيهات الطلاب المعرضين للخطر (تتبع المخاطر)
- تقييم المخاطر بشكل تركيبي عبر 6 إضافات فرعية من نوع `smartdashboardrule`:
  - `loginrecency`: مراقبة حدود عدم النشاط
  - `coursecompletion`: تتبع التقدم المتعثر
  - `grades` و `safetynet70`: التنبيه عند انخفاض متوسط الدرجات
  - `overdue` و `adaptiveplan`: تحديد المواعيد النهائية الفائتة
- تتبع مقاييس تفاعل الطلاب (حداثة تسجيل الدخول، الإكمال، الدرجات، حالة التأخير، الخطط التكيفية)
- التكامل مع خطافات الويب (Webhooks) في n8n للحصول على تنبيهات خارجية فورية عبر رسائل SMS / البريد الإلكتروني / Slack

### التقارير السحرية بالذكاء الاصطناعي ومركز SQL (AI Magic Reports & SQL Hub)
- معالج تقارير مخصص للمسؤولين
- **تحويل اللغة الطبيعية إلى استعلامات SQL**: اطرح أسئلة باللغة الإنجليزية/الطبيعية واترك الذكاء الاصطناعي يُنشئ استعلامات SQL المعقدة تلقائيًا عبر `local_aihub` (مع دعم `core_ai` كبديل احتياطي)
- تحويل نتائج الاستعلامات إلى رسوم بيانية ديناميكية ومخططات إيرادات وجداول مؤشرات الأداء
- حفظ وتحميل وتنفيذ وحذف الرؤى والتقارير المخصصة

### تحليلات المدفوعات
- تتبع الإيرادات الفعلية مقابل التقديرية مع رسوم بيانية للمقارنة التفاعلية
- رسوم بيانية للإيرادات لكل فئة وتصفية حسب عائد الاستثمار (ROI)
- فلاتر للنطاق الزمني وتبديل للعملات
- تصدير السجلات إلى ملفات CSV

### الأخبار والإعلانات الموحدة
- تجميع الإعلانات من منتديات أخبار الموقع والمقررات
- إخفاء فوري للإعلانات بتقنية AJAX وشارات إشعارات

### الإعدادات والتهيئة
- تهيئة أيقونات الاختصارات المخصصة (الاسم، الفئة CSS، الرابط)
- إعدادات وضع حساب المدفوعات
- إعدادات n8n Webhook (الرابط والرمز) لإشعارات المخاطر
- عتبات حساب القواعد المعيارية للمخاطر

### الأمان والخصوصية
- متوافق تمامًا مع **واجهة برمجة تطبيقات الخدمات الخارجية** في موودل (External Services API)
- ينفذ معايير **واجهة الخصوصية** الأساسية في موودل (Privacy API)
- التحقق الآمن من المعلمات وفحوصات الصلاحيات الصارمة

### تعدد اللغات
- متوفر جاهزًا باللغات **الإنجليزية**، **والإسبانية**، **والعربية**
- دمج كامل لوظيفة `get_string()` لتسهيل التعريب
- دعم تنسيق اللغات من اليمين إلى اليسار (RTL)

## تحول سير العمل: موودل الافتراضي مقابل لوحة التحكم الذكية

| المهمة | سير العمل الافتراضي في موودل | سير العمل في لوحة التحكم الذكية | الوقت الموفر |
|---|---|---|---|
| **فحص التصحيح المعلق** | الدخول للمقرر ← فتح الواجب ← فحص التسليمات ← تكرار 10+ مرات | فتح لوحة التحكم الذكية ← عرض **طابور التصحيح** عبر جميع المقررات | **أسرع بنسبة 85%** |
| **تحديد الطلاب المعرضين للخطر** | تصدير السجلات إلى Excel ← حساب حداثة الدخول ومتوسط الدرجات يدويًا | فتح **تنبيهات المخاطر** ← شارات مخاطر فورية ومشغلات n8n Webhook | **أسرع بنسبة 95%** |
| **رؤى البيانات المخصصة** | كتابة استعلامات SQL مخصصة ومعقدة في أدوات قاعدة البيانات | استخدام **التقارير السحرية بالذكاء الاصطناعي** ← كتابة السؤال باللغة الطبيعية وعرض الرسم البياني | **أسرع بنسبة 90%** |
| **الخطة اليومية للطالب** | مراجعة تقويم كل مقرر على حدة | فتح **جدول أعمال اليوم** ← خطة دراسية يومية موحدة | **أسرع بنسبة 80%** |

## التثبيت

### الخيار 1 — تنزيل ملف ZIP
1. قم بتنزيل أحدث ملف ZIP للإصدار من صفحة الإصدارات.
2. في موودل، انتقل إلى **إدارة الموقع ← الإضافات ← تثبيت الإضافات**
3. قم برفع ملف ZIP واتبع التعليمات.

### الخيار 2 — الاستنساخ عبر Git
إذا كان لديك وصول إلى وحدة التحكم (Terminal) في الخادم، انتقل إلى مسار تثبيت موودل الخاص بك:

```bash
cd /path/to/moodle/local
git clone https://github.com/Smartlearn-edu/moodle_local_smartdashboard.git smartdashboard
```
ثم قم بزيارة **إدارة الموقع ← الإشعارات** لإكمال التثبيت.

> **هام:** يجب أن يكون اسم المجلد داخل مسار `/local/` هو **`smartdashboard`**.

## الاستخدام

بعد التثبيت، يمكنك الانتقال إلى لوحة التحكم الذكية عبر الرابط:

```
https://your-site.com/local/smartdashboard/
```

### الوصول حسب الدور

| الدور | ما تراه |
|---|---|
| **الطالب** | لافتة الترحيب، شبكة الاختصارات القابلة للتخصيص، التقدم عبر المقررات، جدول المواعيد النهائية المرمز بالألوان، ملخص الدرجات، وجدول الأعمال اليومي |
| **المعلم** | نظرة عامة على المقرر، تقدم الطلاب والدرجات، طابور التصحيح الموحد، شارات الإنذار المبكر للمخاطر، والخطة اليومية |
| **ولي الأمر / الموجه** | مبدل المتدربين، تصفية البرامج، مخططات تقدم الدرجات، رسوم الرادار لإتقان المواد، خرائط التفاعل الأسبوعي، وتنبيهات الأداء (KPIs) |
| **المدير** | كل ما سبق + تحليلات الفئات، إحصائيات النظام |
| **المسؤول (Admin)** | وصول كامل يشمل تحليلات المدفوعات، تهيئة الإعدادات، القواعد المعيارية، والتقارير السحرية مدعومة بالذكاء الاصطناعي |

### إضافة كتل موودل (Blocks) إلى لوحة التحكم

افتراضيًا، تقيد بعض كتل موودل نفسها للظهور فقط في صفحات المقررات أو لوحة تحكم موودل القياسية. لجعل أي كتلة متاحة للإضافة إلى لوحة التحكم الذكية، تحتاج إلى إضافة نوع صفحة لوحة التحكم (`local-smartdashboard-*`) إلى التنسيقات المسموح بها للكتلة.

**مثال: تعديل كود الكتلة**
1. افتح ملف PHP الرئيسي للكتلة: `blocks/<blockname>/block_<blockname>.php`
2. ابحث عن الدالة `applicable_formats()`.
3. أضف `'local-smartdashboard-*' => true,` إلى المصفوفة المُرجعة.

```php
public function applicable_formats() {
    return [
        'course-view'            => true,
        'site'                   => true,
        'my'                     => true,
        'local-smartdashboard-*' => true, // <-- أضف هذا السطر
    ];
}
```
> **ملاحظة:** تأكد من **مسح جميع ذاكرات التخزين المؤقت** (إدارة الموقع ← التطوير ← مسح ذاكرات التخزين المؤقت) بعد حفظ الملف لترى الكتلة في قائمة "إضافة كتلة"!

## مرجع واجهة برمجة التطبيقات (API)

جميع الوظائف متاحة بشكل آمن عبر **واجهة برمجة تطبيقات الخدمات الخارجية** في موودل (`local_smartdashboard_webservice`):

- `local_smartdashboard_get_cross_course_progress` - بيانات تقدم الطلاب عبر المقررات
- `local_smartdashboard_get_student_detailed_progress` - تفاصيل إكمال الأنشطة لطالب واحد
- `local_smartdashboard_get_grading_overview` - المهام التي تحتاج إلى تصحيح
- `local_smartdashboard_get_system_analytics` - إحصائيات التسجيل على مستوى النظام للمسؤولين/المديرين
- `local_smartdashboard_get_payment_analytics` - تحليلات الإيرادات والمدفوعات
- `local_smartdashboard_save_dashboard_settings` - حفظ تفضيلات إعدادات لوحة التحكم
- `local_smartdashboard_get_dashboard_settings` - استرداد تهيئات لوحة التحكم الحالية
- `local_smartdashboard_get_cross_course_grades` - بيانات درجات الطلاب عبر المقررات
- `local_smartdashboard_get_magic_insight` - الحصول على رؤى التقارير المخصصة والاستعلامات المدعومة بالذكاء الاصطناعي عبر AI Hub
- `local_smartdashboard_save_magic_report` - حفظ تهيئة تقرير سحري مخصص
- `local_smartdashboard_get_saved_reports` - قائمة التقارير السحرية المحفوظة
- `local_smartdashboard_delete_magic_report` - حذف تهيئة تقرير سحري محفوظ
- `local_smartdashboard_get_programs` - قائمة البرامج ومعرفات المقررات المرتبطة بها (`enrol/programs`)
- `local_smartdashboard_dismiss_announcement` - إخفاء إعلان أخباري من لوحة التحكم
- `local_smartdashboard_get_daily_plan` - خطة الدراسة اليومية للطالب (تكامل الخطة التكيفية)
- `local_smartdashboard_get_risk_data` - بيانات تتبع تفاعل الطلاب المعرضين للخطر
- `local_smartdashboard_send_n8n_data` - إرسال بيانات الخُطافات (Webhooks) إلى خوادم أتمتة n8n الخارجية
- `local_smartdashboard_test_ai` - اختبار تكامل الذكاء الاصطناعي لتحليل الدرجات التلقائي
